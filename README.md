# Jobb mint tegnap — képek

Ez a repó csak a posztok képeit tartalmazza, azért hogy az Instagram le tudja tölteni
őket a Meta Graph API számára.

**346 kép:**

| Fájlnév eleje | Mi ez | Darab |
|---|---|---|
| `001-…` … `096-…` | egyedi könyvtanulság-kártyák | 96 |
| `konyv-…` | könyv-karuszellek lapjai (borító + 8 tanulság + záró) | 120 |
| `8-gondolat-…`, `8-igazsag-…`, `8-lecke-…` | tematikus karuszellek lapjai | 120 |
| `bemutatkozo-…` | a bemutatkozó karuszell | 10 |
